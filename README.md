# Canteen Management System 🍔

A simple Python-based canteen ordering and billing system that allows users to view the menu, order items, enter quantities, and generate a final bill.

### Built With
- Python

### Features
- Displays the canteen menu
- Allows multiple item orders
- Takes item quantities
- Calculates the total bill
- Displays the final bill

### How to Run
```bash
python canteen.py
